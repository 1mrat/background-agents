# Claude Rules & Best Practices

## Effective Prompting

- **Be specific and clear**: Provide detailed context and requirements
- **Break down complex tasks**: Split large requests into smaller, manageable parts
- **Provide examples**: Show what you want when possible
- **Use structured formats**: Bullet points, numbered lists, and clear sections help

## Code Assistance

- **Share relevant context**: Include error messages, file structures, and related code
- **Specify language/framework**: Mention the programming language and any frameworks
- **Explain the goal**: Describe what you're trying to achieve, not just what's broken
- **Review suggestions**: Always review and test generated code before using it

## General Interaction Guidelines

- **One task at a time**: Focus on completing one objective before moving to the next
- **Iterate and refine**: Don't hesitate to ask for modifications or improvements
- **Ask follow-up questions**: Clarify anything that's unclear or incomplete
- **Provide feedback**: Let Claude know what works and what doesn't

## Best Practices

- Use clear, descriptive file names and variable names
- Include error handling in code examples
- Consider edge cases and potential issues
- Document important decisions and assumptions
- Test thoroughly before deploying

## Remember

Claude is a tool to assist and enhance your work, not replace your judgment. Always review, understand, and validate the assistance provided.
